## Foresight

**Predictive Kubernetes Autoscaling Service**

Foresight is a lightweight, pluggable Go service designed for predictive Kubernetes autoscaling.

Instead of waiting for CPU or memory spikes, it analyzes business signals such as traffic surges, flash sales, and market volatility to predict increased demand and proactively scale workloads.

# ⚙️ Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/maniyarjakeer0209-source/my-portfolio.git
cd my-portfolio

2. Create a virtual environment
python -m venv venv
3. Activate the virtual environment

Windows:

venv\Scripts\activate

Linux / macOS:

source venv/bin/activate
4. Install dependencies
pip install -r requirements.txt

5. Configure environment variables

Create a local .env file with the required Django configuration.

Never commit .env or production secrets to GitHub.

6. Apply migrations
python manage.py migrate
7. Start the development server
python manage.py runserver

Open:

http://127.0.0.1:8000/

🔐 Security

Production-sensitive configuration is kept outside the repository using environment variables.

This includes:

Django SECRET_KEY
Database credentials
API keys
Email credentials
Other production secrets

.env files and local database files are not committed to the repository.
